# Professional Development Roadmap — 2026–2028

> **Career Direction:** Building toward an **Azure AI / Cloud AI Engineer** profile by combining an existing foundation in software development, networking, systems, security, databases, and Microsoft Azure with Python and production-grade AI engineering.

## Roadmap

### 01 — Python Engineering · Foundation
**Focus:** Develop strong Python skills for backend, automation, cloud, and AI workloads.

- Core Python, OOP, modules, exceptions, virtual environments
- Async programming, JSON, HTTP and REST APIs
- SQL integration, testing and automation
- Practical Python projects rather than course-only learning

**Target window:** 2026

---

### 02 — Microsoft Azure · Cloud Foundation
**Focus:** Strengthen hands-on Azure administration and infrastructure skills while working toward **AZ-104**.

- Azure Virtual Networks, subnets, NSGs and virtual machines
- Microsoft Entra ID, RBAC, storage and monitoring
- Azure CLI and infrastructure fundamentals
- Apply existing networking, Windows Server, virtualization and firewall knowledge in Azure

**Target window:** 2026

---

### 03 — Cloud Development · Production Skills
**Focus:** Connect software development with modern cloud engineering practices.

- Git & GitHub
- Linux
- FastAPI and REST API development
- PostgreSQL / SQL
- Docker and containerization
- CI/CD and Azure deployment

**Target window:** 2026–2027

---

### 04 — AI Engineering · LLM Applications
**Focus:** Move from conventional cloud applications into practical AI systems.

- LLM APIs and structured outputs
- Embeddings and vector databases
- Retrieval-Augmented Generation (RAG)
- Tool / function calling
- Evaluation, testing and guardrails

**Target window:** 2027

---

### 05 — AI Agents & MCP · Agentic Systems
**Focus:** Design AI agents that can reason over information and interact safely with external tools and services.

- Agent architecture and workflows
- Tool integration
- Model Context Protocol (MCP)
- Multi-step workflows
- Reliability, observability and security

**Target window:** 2027

---

### 06 — Azure AI · Cloud AI Specialization
**Focus:** Combine AI engineering with the Microsoft Azure ecosystem.

- Azure AI services
- Azure OpenAI
- Microsoft Foundry
- Deployment and monitoring of AI applications and agents
- Preparation for relevant Microsoft Azure AI credentials

**Target window:** 2027–2028

---

### 07 — Portfolio & Market Readiness · Professional Integration
**Focus:** Demonstrate the complete skill set through production-oriented projects.

Planned portfolio direction includes projects combining **AI + Azure + Networking/Security**, such as an AI-assisted network operations or IT support system, alongside cloud-deployed AI applications with documented architecture and source code.

**Target window:** 2028

## Target Professional Profile

**Azure AI / Cloud AI Engineer**

`Networking & Security → Azure → Python → Cloud Development → AI Engineering → AI Agents & MCP → Azure AI → Production Portfolio`

### Existing foundation being built upon

C# / .NET · SQL & SQLite · Networking · Windows Server · Virtualization · FortiGate · Microsoft Azure · Software Development

---

*This roadmap represents an active professional-development plan. Technologies listed as future stages are learning targets and should not be interpreted as completed qualifications until demonstrated through projects, experience, or certification.*
